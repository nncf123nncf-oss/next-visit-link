# 次回予約カレンダーリンク（next-visit-link）

次回の予約の日時・店名・所要時間を入れてリンクを作ると、お客さんがそのリンクを開くと、自分のカレンダーに予定を追加するボタンが出る1ページの道具です（iPhone実機でカレンダーに入るかは未確認）。

- 予約の内容はURLの `#` 以降に入ります。サーバー・アカウントは使いません。予約の受付・変更はしません
- カレンダーへの追加は2経路: `.ics` ファイル（iPhoneの標準カレンダーなど）と、Googleカレンダーへの追加リンク
- iPhone・iPadのSafariでは、`.ics` を blob URL の本物のリンク（`<a download target="_self">`）として置き、利用者が直接タップする方式にしています。iPhoneのChrome・アプリ内ブラウザ（LINE・Instagram等）では、Safariで開き直す案内とアドレスのコピーを出します
- お客さんの名前・電話番号・メールアドレスは入力項目にありません。リンク・メールアドレス・電話番号らしい文字は入れられません
- 作る側の下書き（店名・所要時間・ひと言・お知らせ）だけ、お使いの端末のブラウザ（localStorage）に保存します。日付と時刻は保存しません
